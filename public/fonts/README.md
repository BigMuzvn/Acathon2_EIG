# Manrope

Police variable Manrope, graisses 200 à 800, hébergée localement au format WOFF2. Sous-ensembles Google Fonts `latin` et `latin-ext`, récupérés le 9 septembre 2026.

- `manrope-latin-variable.woff2` : latin, accents français et symbole euro.
- `manrope-latin-ext-variable.woff2` : caractères latins étendus.
- `manrope.css` : déclarations `@font-face` locales avec `font-display: swap`.
- `OFL-Manrope.txt` : licence SIL Open Font License 1.1 et attribution complètes.
